AD group routes

An AD group carries no pointer to the system it belongs to, so a naming convention is all there is to go on. A route says which application or service should hold groups matching a pattern, and the AD groups page shows the match. Routes only suggest a home — nothing is created from them without someone confirming it, and the sync never reads them.
