Entra group routes

A cloud group carries no pointer to the system it belongs to, so its display name is all there is to go on. A route says which application or service should hold the groups whose display name matches a pattern, and the Entra groups page shows the match. An application always outranks a service, whatever the priorities say; priority orders the rest. Only groups that can back an access level are routed: a group synced from Active Directory is an AD group, which the {% if AD_ENABLED %}AD group routes{% else %}AD group routes{% endif %} place.

For an ordinary application a route only suggests a home — nothing is created without someone confirming it. For one marked Holds groups below (Dynamic Entra groups on the application), a route also creates and retires its access levels automatically, for every matching assignable cloud group nobody has adopted by hand.
